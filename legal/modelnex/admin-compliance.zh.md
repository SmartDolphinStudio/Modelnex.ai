# 管理员合规确认

本页面用于 ModelNex.AI / Sub2API 管理后台的管理员操作确认。

管理员在继续使用后台前，应确认已经阅读并理解以下要求：

- 不在代码、日志、截图、工单或提交记录中泄露 API key、token、密码、上游密钥或用户敏感信息。
- 不删除、不遮盖、不破坏 Sub2API 及其他开源组件保留的原版权、许可证和许可备份。
- 对账号、API key、渠道、限流、计费、反代、Redis、PostgreSQL、支付和风控相关配置的修改应保留可审计记录。
- 对生产或准生产环境的部署、重启、数据迁移和配置变更应先确认影响范围。

完整法律声明、用户协议、隐私政策、风险提示、开源协议和 AI 使用策略以文档站为准：https://doc.modelnex.ai
